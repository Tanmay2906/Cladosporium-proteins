## D. Provenance rules in force

1. No external sequence enters this project outside `data/raw/` or `data/reference/` via the retrieval pipeline, and every such file is registered in `data/manifests/retrieval_manifest.csv` before use.
2. Provenance manifest `config/human_proteome.txt` stores metadata only — **never sequences**.
3. Checksums in §A are of the **files as stored**; the sequence-only digests quoted in `target_selection_rationale.md` are of the bare sequence and use different bases (md5 vs file-md5); both are shown to avoid silent mismatch.
4. Anything marked PENDING must be recorded here, in the manifest (new R-row), and dated at execution time; this document is updated in the same commit-like step as the execution.
5. This project has **no GitHub/remote configured**; provenance integrity rests entirely on this ledger + checksums, not on VCS history.
